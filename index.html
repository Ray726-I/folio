08 // trust boundary

Opening a file is not a request.

  • ✓Sanitized HTML. ammonia strips Markdown HTML to a safe subset before it reaches the DOM.
  • ✓Remote images blocked. A local placeholder appears until you enable loading in the command window.
  • ✓No referrer. When enabled, images use referrerpolicy="no-referrer".
  • ✓Path boundary. Relative links resolve only inside the document's folder or its descendants.
  • ✓Scheme policy. Web links go to the default browser; data: links are removed.
  • ✓Navigation allowlist. Only the app origin is a page. file: and about:srcdoc are rejected.
  • ✓Checkbox spoofing closed. Raw HTML cannot forge task inputs — even with mixed-case data-sourcepos.
FIG. 08 — sanitize → allow → clean preview

KaTeX uses restrictive trust; Mermaid runs at securityLevel: strict.

11 // file discipline

The boring parts are the product.

Saving a text file sounds solved until it happens over a network share, a synced folder, or another editor. Folio treats the write as a transaction.

Atomic save
Write a temporary sibling, then rename — the document lock is released for the native save dialog. Readers never observe a half-written file.
Content fingerprint
SHA-256 of the bytes detects external edits and offers Reload, Overwrite or Cancel.
Preserve what exists
CRLF endings, UTF-8 BOM and permissions survive; new files follow the process umask.
Bounded scanning
Folders cap at 5,000 entries and 12 levels; unreadable entries are skipped and reported.
Hard limits
20 MB per document, 10 MB per local image, UTF-8 only — enforced, not implied.
FIG. 11 — temp file → rename → final file

Every line on the left has a Rust test behind it: conflict detection, atomic behaviour, CRLF/BOM and permission preservation, new-file umask, tolerant folder scanning.

12 // runtime

Nothing loads until the document needs it.

0 frontend build steps

4.2 MB vendored KaTeX + Mermaid, loaded on demand
0 CDNs or render services in the path
document.md → Rust parser → sanitized HTML → preview ┄┄→ KaTeX / Mermaid only if present read + edit work offline
FIG. 12 — payloads wake only when reached

Fonts are shipped with the app, so the document doesn't reflow when the network disappears. The reader defaults to Source Serif 4; a command-window toggle switches the document to sans without touching the interface.

Diagrams are re-rendered when the theme changes, so they always match the palette — including a live Omarchy theme. Remote images stay a deliberate opt-in, never a default.
